Ultimate Weather, Waveshare 7 inch.

Repo: https://github.com/stefi01/Ultimate-Weather-Station-Earthquake-Lightning-ISS
Branch main. Folder ota.

The screen reads only these two files:
  version.txt
  sky_7in.bin

version.txt is 1.3. That matches SKY_VER in the sketch.
CHECK only offers a higher number.

sky_7in.bin is the 23 Nov 2026 11:26 PM export, with the version number set to 1.3.
The lamp stays on, DIM is 5/8, MID is 6/8, the home page draws when the weather read finishes, and the panel is reset before the picture starts and again after Wi-Fi.

Arduino settings for that compile are in ARDUINO-IDE.txt.
The four cable-flash files and the addresses are in bin-files.
